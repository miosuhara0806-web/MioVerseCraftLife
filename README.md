# MioVerse 小径の工房

採集 → 加工 → 住人への納品を試す、戦闘・時間制限のない生活ゲームの試作版です。

## 遊び方

`index.html` をブラウザで開きます。スマホや GitHub Pages では、`index.html`・`style.css`・`game.js`・`app.js` を同じフォルダで配信してください。ビルド・依存パッケージ・外部通信は不要です。

1. 採集で枝・ツル草・野花を選びます。毎回2個、初期は1日3回、固定依頼9件達成後は1日5回まで採集できます。
2. 加工で素材を消費して次の品物をつくります。1個ずつ、または素材を使ってまとめて加工できます。
3. 依頼で布袋・染料・小箱を各1個納品します。依頼は各1回限り、達成後も採集と加工は続けられます。
4. 最初の3件をすべて納品すると、第2段階の3件（カーテン・壁掛け・染め布）が解放されます。こちらも「1個届ける」で手動納品します。最初の3件のお礼は引き続き読み返せます。

最初の布袋：ツル草を1回採集 → 植物繊維2個 → 糸2個 → 布1個 → 布袋1個 → ナカちゃんへ納品。
小箱：枝を2回採集 → 木材2個 → 板材2個 → 小箱1個。
染料：野花を1回採集 → 乾燥花2個 → 染料1個。

加工画面の「組み合わせのしごと」に追加したレシピ：

- 布1個 ＋ 染料1個 → 染め布1個
- 染め布2個 ＋ 糸1個 → カーテン1個
- 板材1個 ＋ 染め布1個 → 壁掛け1個

複数素材のうち一つでも不足していれば加工できず、他の素材も消費しません。「まとめて」は全素材から作れる最大数を使います。染め布は中間素材、カーテン・壁掛けは完成品の棚に表示されます。追加レシピは最初から利用でき、追加依頼のみ段階解放されます。

## 第3段階：素材の使い道を増やす

最初の6件をすべて手動納品すると、花のリース・クッション・布張り小箱の依頼3件が解放されます。全9件とも作成だけでは達成せず、納品時に1個消費します。

- ツル草2個 ＋ 乾燥花2個 ＋ 糸1個 → 花のリース1個
- 小箱1個 ＋ 染め布1個 → 布張り小箱1個
- 染め布2個 ＋ 植物繊維2個 ＋ 糸1個 → クッション1個

新しい3品は完成品の棚に表示されます。レシピは最初から利用できます。乾燥花を染料にするかリースにするか、小箱を納品するか追加加工するかを選べます。
旧セーブの在庫・達成状況を保持し、6件達成済みなら第3段階を解放します。新在庫は0から開始します。解放段階は各段階より前の依頼の達成状況から復元し、在庫・達成状況とともに保存します。

## 日常依頼

固定依頼9件をすべて納品すると、ナカちゃん・律さん・秘書トワ・軽快トワ・シル・黒子・アルト・碧博士の日常依頼から、合計3件が届きます。通常時は45件の専用プールから既存レシピと家具レシピだけを使って抽選し、同日の依頼重複と直前の同枠再登場を避けます。

本編クリア後は、通常の日常依頼3枠とは別に「裏庭からのお届け」枠が有効になります。裏庭依頼がない状態で日付が進むたび、35%の確率でじゃがいも・にんじん・小麦のいずれかを2個届ける依頼が1件届きます。通常3枠がすべて未達成でも抽選されます。未達成の裏庭依頼は翌日へ持ち越し、新しい依頼は重ねません。

裏庭依頼の依頼主は8人の住人から従来と同じ重みで選びます。本編クリア時点では全員お礼済みのため均等です。納品すると通常の日常依頼と同じく、その住人の達成数に加算されます。旧方式で通常3枠内に生成済みの畑依頼は、読み込み時に独立した裏庭依頼枠へ移行します。

日常依頼も完成品を作っただけでは達成になりません。依頼画面で手動納品すると指定数を在庫から消費し、その日は「お届け済み」になります。未達成の依頼は翌日へ持ち越し、お届け済みの枠だけが「今日は休む」で次の日になった際に入れ替わります。期限・失敗ペナルティはありません。

現在の3枠、各枠の達成状態、直近の抽選履歴は既存の保存キーに追加して保存します。9件達成済みの旧セーブには初回の3件だけを安全に補い、在庫・日数など既存の進行は初期化しません。

## 図鑑

図鑑には現在の全21種類を表示します。未発見品は名前や作り方を伏せ、一度でも採集・加工した品は在庫が0になっても発見済みとして残ります。発見済み品は現在の在庫と、レシピがあれば必要素材を確認できます。旧セーブで18種類を発見済みでも、新しい家具3種類は制作するまで未発見です。

発見状態は従来の保存キー内の `discovered` に記録します。旧セーブでこの項目がない場合だけ、在庫と納品済み依頼からレシピを再帰的にたどって過去の発見を推定し、その結果を保存します。未達成の日常依頼や抽選履歴だけでは入手済みとは判定しません。

## 家具のしごと

加工画面の「家具のしごと」で、板材2個から木枠1個、木枠1個と板材2個から小さな棚1個、木枠1個・染め布1個・植物繊維1個から布張りスツール1個を作れます。木枠は加工素材、棚とスツールは完成品です。家具の配置機能はありません。

家具を求める日常依頼5件は、既存の依頼枠を変えず、翌日以降の通常抽選に加わります。

## 日数と採集回数

1日目・採集残り3回から開始します。固定依頼9件をすべて納品すると、その日に使った採集回数を維持したまま上限が5回になります。採集1回で残り回数を1消費し、0回になると採集ボタンが無効になります。加工・在庫確認・依頼確認・納品は回数を消費しません。

工房の「今日は休む」で確認画面を開き、「休んで次の日へ」で翌日・残り3回（9件達成後は5回）になります。「まだ作業する」またはEscapeキーでは何も変わりません。残り回数があっても休めますが、翌日への持ち越しはありません。

日付は休む操作でだけ進み、現実の時刻とは連動しません。依頼期限・日数制限・ペナルティはありません。在庫・依頼進行は翌日も引き継ぎます。

日数（day）と残り採集回数（gathersLeft）は既存の保存キーへ一緒に保存します。適用済み上限（gatherLimit）も保存し、旧セーブの9件達成済み状態では残り回数を初回だけ2回増やします。日数・在庫・依頼進行は維持し、再読み込みで回数が繰り返し増えることはありません。

## 本編クリア後の裏庭

最終特別依頼の完了イベントを読むと、7番目の画面として裏庭が解放されます。3区画の畑に、じゃがいも（2日）・にんじん（3日）・小麦（4日）を植えられます。日付は「今日は休む」で進み、成長後に収穫すると2個が在庫へ入ります。栽培状態と収穫物の在庫は既存の保存データへ追加して保存します。

## ファイル構成

- `index.html`：画面の土台
- `style.css`：スマホ対応のレイアウトと仮UI（画像・外部フォントなし）
- `game.js`：素材、レシピ、固定・日常依頼、採集・加工・納品・翌日更新・図鑑記録のルール
- `app.js`：7画面の表示、操作、localStorage保存
- `test-game.cjs`：基本ループと消費処理の確認（`node test-game.cjs`）

## 調整と保存

### セーブのバックアップ・復元

工房の下部で「セーブを書き出す」「セーブを読み込む」を利用できます。書き出しファイル名は `mioverse-komichi-save-YYYYMMDD-HHMM.json`（端末の日時）です。JSONは `{ game: "MioVerseCraftLife", exportedAt: "ISO日時", saveVersion: 2, save: セーブ本体全体 }` の構造で、全進捗・在庫・依頼・図鑑・裏庭・もてなし・思い出・今日のまかない等を含みます。ファイルは端末外にも保管してください。

読み込みはJSON・ゲーム名・対応バージョン・セーブ本体の主要項目と型を確認し、既存の `restore` で復元内容を準備してから上書き確認を表示します。ファイル選択や確認のキャンセル・不正ファイルでは変更しません。描画が成功してから同じlocalStorageキーへ一度だけ書き込み、描画または保存に失敗した場合は元の実行状態へ戻します。保存失敗時もlocalStorageの元の値は維持されます。復元後は工房へ即座に反映し、自動保存・ゲーム内セーブ形式・保存バージョンは従来どおりです。ファイル選択とダウンロードにはブラウザ標準機能を使います。

### 加工画面の折りたたみ

加工画面は制作系統ごとに折りたたみ、件数を利用可能なレシピ定義から自動集計します。各系統内は既存のレシピ定義順を維持し、前段の加工から完成品へ追える並びです。これは加工画面だけの表示分類で、レシピ定義・在庫・図鑑の分類や処理には変更を加えません。枝・ツル草・野花・粘土は採集素材のままで、加工レシピには追加しません。

| 系統 | レシピ（工程順） |
| --- | --- |
| 木のしごと | 木材、板材、小箱、木枠 |
| 布のしごと | 植物繊維、糸、布、布袋 |
| 花のしごと | 乾燥花、染料、染め布 |
| 土のしごと | 素焼き、小皿、マグカップ、花瓶 |
| 組み合わせのしごと | カーテン、壁掛け、花のリース、布張り小箱、クッション |
| 家具のしごと | 小さな棚、布張りスツール |
| 料理 | 既存料理19品を定義順で表示 |

乾燥花から染料、染め布までを花・染色系統へまとめます。木枠は木工系統の中間素材として表示し、家具の完成品は独立した系統です。カーテンは染め布＋糸、リースはツル草＋乾燥花＋糸、クッションは染め布＋植物繊維＋糸を使うため、壁掛け・布張り小箱と同じ「組み合わせのしごと」に置きます。小箱と木枠、陶器3品など並行した工程は、説明文でも分岐として示します。

通常の加工画面への移動では全カテゴリを閉じます。依頼などの作り方から移動すると、対象レシピのカテゴリだけを開き、従来どおり強調・フォーカス・スクロールします。複数カテゴリを同時に開け、作成による画面更新では開閉状態を維持します。開閉状態は一時的なUI状態で、セーブデータには保存しません。

### 今日のまかない

本編クリア後、工房に「今日のまかない」が表示されます。8人から同確率で選ばれた今日のお客さんに、在庫のある料理から1品を出し、A〜Eの5パターンの短い会話を同確率で楽しめます。料理の対象は料理定義から取得します。

当日の住人IDと選択料理IDが一致する場合は、汎用会話の抽選をせず専用リアクションを必ず表示します。対象はナカちゃん／バタークッキー、律／魚の塩焼き、秘書トワ／きのこのクリームパスタ、軽快トワ／ふんわりスクランブルエッグ、シル／野菜スープ、黒子／素朴なパン、アルト／素朴なプリン、碧博士／きのこのオムレツです。既存A〜Cの本文と保存項目は維持し、新しい会話の既読状態は保存しません。碧博士の共通住人名・まかない名・もてなしの話者ラベルは「🧪碧博士」に統一し、既存の台詞本文・地の文・内部IDは維持します。

会話の最後の「ごちそうさま」で料理1個を消費し、その日のまかないを完了します。選択や会話の途中でキャンセル・Escape・再読み込みをすると、消費も完了も発生しません。「今日は休む」で翌日へ進むと、実施・未実施にかかわらず新しいお客さんを抽選します。同じ住人が続く場合もあります。報酬や依頼・住人・本編・もてなしの進捗は変わらず、思い出にも記録しません。

保存キー・保存バージョンを維持し、`dailyMeal: { day, resident, completed }` だけを追加します。本編クリア前は `null` です。クリア済み旧セーブでは当日分だけ補い、同じ日の読み込みでは住人と完了状態を保持します。ゲーム内日数は既存と同様、大きな日数の文字列保存にも対応します。

### 料理依頼の調整・スクランブルエッグ

クリア後の料理に「ふんわりスクランブルエッグ」（卵2個 → 1皿）を追加しました。さらに「素朴なプリン」（卵2個＋牛乳1個＋砂糖1個 → 1皿）と「塩バターパン」（小麦2個＋塩1個＋バター1個 → 1個）を追加し、料理は全19品、クリア後の図鑑は全57項目です。新料理も既存と同じ調理・在庫・発見記録・手動納品処理を使います。プリンと塩バターパンの依頼は完成品1個を要求し、既存の外来食材使用料理と同じウェイト1です。

現在の通常依頼は最大4枠です。クリア後、未完了の料理依頼を持ち越しておらず、新規依頼を補充できる場合は、補充分の1件を必ず料理依頼にします。料理依頼は最大1件、未完了4件なら補充せず、裏庭依頼は従来どおり独立した最大1枠です。住人の抽選ウェイトと外来食材料理のウェイトは維持し、スクランブルエッグは自給素材系のウェイト2です。

保存キーと保存バージョンは維持します。既存4枠は読み込みだけでは入れ替えず、新料理の在庫がない旧セーブには0を補います。既存進捗・在庫・図鑑発見状態は引き継ぎます。

素材・レシピ・依頼は `game.js` の定義で変更できます。加工の出力は1回につき1個です。
追加した複数素材レシピは `inputs` に素材IDと必要数を定義しています。既存の単一素材レシピも同じ加工処理で扱います。
保存キーは以前と同じです。旧セーブの在庫・達成状況を引き継ぎ、新しい在庫は0から開始します。最初の3件を達成済みなら、第2段階を自動で解放します。新在庫・追加依頼の達成状況・解放段階（`unlockedStage`）を保存し、読み込み時は最初の3件の達成状況から解放段階を整合させます。
進行状況は操作ごとにブラウザのlocalStorage（キー `mioverse-craft-v1`）へ自動保存します。同じブラウザ・同じ配信元で再開できます。別端末との同期はありません。ブラウザのデータ消去で保存内容も消えます。ファイル直接起動時やプライベートモードなどで保存できない場合は画面に表示します。安定した保存には HTTP(S) 配信を推奨します。複数タブで同時に遊ぶと最後の保存が優先されるため、1つのタブで遊んでください。

GitHub Pagesではこのフォルダのファイルをリポジトリへ置き、Settings → Pagesで対象ブランチのルートを公開対象にしてください。

## 最初からテストする場合

完成品を作るだけでは依頼は達成されません。3人とも依頼画面の「1個届ける」を押すと、完成品を1個消費して達成します。以前に納品した保存データは、更新後も達成済みとして復元されます。

初期化する場合は、ゲームを開いているブラウザの開発者ツール（F12）の Console で次を実行します。このゲームの在庫・依頼達成状況が消えるので、最初からやり直したい場合だけ実行してください。他のゲームの保存データは消しません。他に開いているこのゲームのタブは先に閉じてください。

```js
localStorage.removeItem('mioverse-craft-v1');
location.reload();
```

画面操作・保存の回帰テスト：`node test-app.cjs`（ブラウザの保存データを変更せず、メモリ上の仮画面・保存領域で検証）。

料理・畜産・天候・季節・好感度・アクションなどは実装していません。
